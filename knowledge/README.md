# База знаний (Markdown)

Все файлы `*.md` в этой папке (кроме `README.md` и имён, начинающихся с `_`) читаются при старте бота и **подмешиваются в системный запрос** в **режимах**, где **нужны** **факты** **о** **услугах/политике** (см. [../prompts/](../prompts/): **роль** **Анны** и **сценарии** **диалога** **заданы** **там**).

**Порядок:** по имени файла (префикс `20-`, `30-` — порядок склейки).

**Переменные окружения:** `KNOWLEDGE_DIR` — каталог с фактовыми `.md` (по умолчанию `./knowledge`). **Сценарные** шаблоны: `PROMPTS_DIR` (по умолчанию `./prompts`).

Черновики можно назвать `_notes.md` — они не загружаются.

Типовой набор: `20-product.md` (услуги, веса), `30-policies.md` (ограничения), `40-faq.md` (готовые ответы).
