# База знаний (Markdown)

Все файлы `*.md` в этой папке (кроме `README.md` и имён, начинающихся с `_`) читаются при старте бота и подставляются в **системный промпт** перед служебными правилами (JSON, этапы заявки).

**Порядок:** по имени файла (латиница/цифры в префиксе помогают: `10-agent.md`, `20-product.md`).

**Переменная окружения:** `KNOWLEDGE_DIR` — абсолютный или относительный путь к каталогу с `.md`. По умолчанию используется `./knowledge` от рабочей директории процесса.

Черновики можно назвать `_notes.md` — они не загружаются.

Типовой набор: `10-agent.md` (роль, Анна, приветствие), `20-product.md` (услуги, веса), `30-policies.md` (ограничения), `40-faq.md` (готовые ответы).
